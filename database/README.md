# Настройка EduAI

## Подключение Supabase

1. Создайте проект Supabase и скопируйте URL проекта и его publishable key.
2. В корне приложения создайте `.env`:

   ```env
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_PUBLISHABLE_KEY=your-publishable-key
   PORT=5000
   ```

   Не добавляйте `service_role` key в приложение или клиентский код.
3. В Supabase SQL Editor выполните `database/schema.sql`. Таблица использует Row Level Security и разрешает каждому пользователю читать и изменять только собственный прогресс.
4. Включите Email в **Authentication → Providers**. Если подтверждение адреса включено, после регистрации откройте ссылку из письма, затем войдите на платформе.
5. Запустите `npm start` и откройте `http://localhost:5000`.

Без переменных Supabase кабинет и уроки доступны для просмотра, а API авторизации сообщает о необходимости настройки. Регистрация и синхронизация прогресса включаются после настройки проекта и схемы.
Для публичного запуска храните значения в секретах хостинга и используйте HTTPS.

## API

- `POST /api/auth/register` — создание аккаунта по имени, почте и паролю.
- `POST /api/auth/login` — вход.
- `POST /api/auth/refresh` — обновление сессии.
- `GET /api/auth/me` — проверка текущего пользователя.
- `POST /api/auth/logout` — завершение текущей сессии.
- `GET /api/progress` — получение прогресса авторизованного пользователя.
- `POST /api/progress` — сохранение завершённого урока.
- `GET /api/health` — проверка состояния сервера.
